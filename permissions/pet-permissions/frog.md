# Frog
| Permission Node | Description |
| - | - |
| pet.type.frog | Will allow the player to spawn the Frog pet |
| pet.type.frog.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.frog.fly | Will allow the Frog to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.frog.hat | Will allow the Frog to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.frog.mount | Will allow the Frog to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.frog.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data frog</mark>) |
| pet.type.frog.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.frog.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.frog.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.frog.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.frog.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.frog.data.variant | Will allow the player to view/toggle the 'Variant' Data Item |
| pet.type.frog.data.croaking | Will allow the player to view/toggle the 'Croaking' Data Item |
| pet.type.frog.data.tongue | Will allow the player to view/toggle the 'Tongue' Data Item |
