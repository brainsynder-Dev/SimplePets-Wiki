# Creaking
| Permission Node | Description |
| - | - |
| pet.type.creaking | Will allow the player to spawn the Creaking pet |
| pet.type.creaking.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.creaking.fly | Will allow the Creaking to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.creaking.hat | Will allow the Creaking to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.creaking.mount | Will allow the Creaking to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.creaking.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data creaking</mark>) |
| pet.type.creaking.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.creaking.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.creaking.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.creaking.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.creaking.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
