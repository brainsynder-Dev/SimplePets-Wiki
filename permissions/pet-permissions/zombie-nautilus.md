# Zombie Nautilus
| Permission Node | Description |
| - | - |
| pet.type.zombienautilus | Will allow the player to spawn the Zombie Nautilus pet |
| pet.type.zombienautilus.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.zombienautilus.fly | Will allow the Zombie Nautilus to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.zombienautilus.hat | Will allow the Zombie Nautilus to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.zombienautilus.mount | Will allow the Zombie Nautilus to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.zombienautilus.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data zombie_nautilus</mark>) |
| pet.type.zombienautilus.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.zombienautilus.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.zombienautilus.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.zombienautilus.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.zombienautilus.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.zombienautilus.data.baby | Will allow the player to view/toggle the 'Baby' Data Item |
| pet.type.zombienautilus.data.saddled | Will allow the player to view/toggle the 'Saddled' Data Item |
| pet.type.zombienautilus.data.armor | Will allow the player to view/toggle the 'Armor' Data Item |
| pet.type.zombienautilus.data.variant | Will allow the player to view/toggle the 'Variant' Data Item |
