# Copper Golem
| Permission Node | Description |
| - | - |
| pet.type.coppergolem | Will allow the player to spawn the Copper Golem pet |
| pet.type.coppergolem.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.coppergolem.fly | Will allow the Copper Golem to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.coppergolem.hat | Will allow the Copper Golem to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.coppergolem.mount | Will allow the Copper Golem to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.coppergolem.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data copper_golem</mark>) |
| pet.type.coppergolem.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.coppergolem.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.coppergolem.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.coppergolem.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.coppergolem.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.coppergolem.data.oxidation | Will allow the player to view/toggle the 'Oxidation' Data Item |
