# Bogged
| Permission Node | Description |
| - | - |
| pet.type.bogged | Will allow the player to spawn the Bogged pet |
| pet.type.bogged.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.bogged.fly | Will allow the Bogged to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.bogged.hat | Will allow the Bogged to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.bogged.mount | Will allow the Bogged to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.bogged.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data bogged</mark>) |
| pet.type.bogged.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.bogged.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.bogged.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.bogged.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.bogged.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.bogged.data.sheared | Will allow the player to view/toggle the 'Sheared' Data Item |
