# Sulfur Cube
| Permission Node | Description |
| - | - |
| pet.type.sulfurcube | Will allow the player to spawn the Sulfur Cube pet |
| pet.type.sulfurcube.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.sulfurcube.fly | Will allow the Sulfur Cube to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.sulfurcube.hat | Will allow the Sulfur Cube to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.sulfurcube.mount | Will allow the Sulfur Cube to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.sulfurcube.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data sulfur_cube</mark>) |
| pet.type.sulfurcube.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.sulfurcube.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.sulfurcube.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.sulfurcube.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.sulfurcube.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.sulfurcube.data.size | Will allow the player to view/toggle the 'Size' Data Item |
