# Tadpole
| Permission Node | Description |
| - | - |
| pet.type.tadpole | Will allow the player to spawn the Tadpole pet |
| pet.type.tadpole.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.tadpole.fly | Will allow the Tadpole to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.tadpole.hat | Will allow the Tadpole to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.tadpole.mount | Will allow the Tadpole to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.tadpole.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data tadpole</mark>) |
| pet.type.tadpole.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.tadpole.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.tadpole.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.tadpole.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.tadpole.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
