# Allay
| Permission Node | Description |
| - | - |
| pet.type.allay | Will allow the player to spawn the Allay pet |
| pet.type.allay.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.allay.fly | Will allow the Allay to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.allay.hat | Will allow the Allay to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.allay.mount | Will allow the Allay to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.allay.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data allay</mark>) |
| pet.type.allay.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.allay.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.allay.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.allay.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.allay.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.allay.data.dancing | Will allow the player to view/toggle the 'Dancing' Data Item |
