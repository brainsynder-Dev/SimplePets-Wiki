# Happy Ghast
| Permission Node | Description |
| - | - |
| pet.type.happyghast | Will allow the player to spawn the Happy Ghast pet |
| pet.type.happyghast.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.happyghast.fly | Will allow the Happy Ghast to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.happyghast.hat | Will allow the Happy Ghast to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.happyghast.mount | Will allow the Happy Ghast to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.happyghast.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data happy_ghast</mark>) |
| pet.type.happyghast.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.happyghast.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.happyghast.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.happyghast.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.happyghast.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.happyghast.data.baby | Will allow the player to view/toggle the 'Baby' Data Item |
| pet.type.happyghast.data.color | Will allow the player to view/toggle the 'Color' Data Item |
