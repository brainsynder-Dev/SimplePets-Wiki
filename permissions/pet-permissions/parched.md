# Parched
| Permission Node | Description |
| - | - |
| pet.type.parched | Will allow the player to spawn the Parched pet |
| pet.type.parched.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.parched.fly | Will allow the Parched to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.parched.hat | Will allow the Parched to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.parched.mount | Will allow the Parched to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.parched.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data parched</mark>) |
| pet.type.parched.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.parched.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.parched.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.parched.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.parched.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
