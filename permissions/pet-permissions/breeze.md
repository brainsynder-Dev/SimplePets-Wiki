# Breeze
| Permission Node | Description |
| - | - |
| pet.type.breeze | Will allow the player to spawn the Breeze pet |
| pet.type.breeze.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.breeze.fly | Will allow the Breeze to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.breeze.hat | Will allow the Breeze to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.breeze.mount | Will allow the Breeze to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.breeze.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data breeze</mark>) |
| pet.type.breeze.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.breeze.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.breeze.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.breeze.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.breeze.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
