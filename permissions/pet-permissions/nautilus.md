# Nautilus
| Permission Node | Description |
| - | - |
| pet.type.nautilus | Will allow the player to spawn the Nautilus pet |
| pet.type.nautilus.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.nautilus.fly | Will allow the Nautilus to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.nautilus.hat | Will allow the Nautilus to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.nautilus.mount | Will allow the Nautilus to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.nautilus.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data nautilus</mark>) |
| pet.type.nautilus.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.nautilus.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.nautilus.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.nautilus.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.nautilus.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.nautilus.data.baby | Will allow the player to view/toggle the 'Baby' Data Item |
| pet.type.nautilus.data.saddled | Will allow the player to view/toggle the 'Saddled' Data Item |
| pet.type.nautilus.data.armor | Will allow the player to view/toggle the 'Armor' Data Item |
