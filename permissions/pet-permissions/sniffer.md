# Sniffer
| Permission Node | Description |
| - | - |
| pet.type.sniffer | Will allow the player to spawn the Sniffer pet |
| pet.type.sniffer.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.sniffer.fly | Will allow the Sniffer to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.sniffer.hat | Will allow the Sniffer to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.sniffer.mount | Will allow the Sniffer to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.sniffer.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data sniffer</mark>) |
| pet.type.sniffer.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.sniffer.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.sniffer.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.sniffer.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.sniffer.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.sniffer.data.baby | Will allow the player to view/toggle the 'Baby' Data Item |
| pet.type.sniffer.data.state | Will allow the player to view/toggle the 'State' Data Item |
