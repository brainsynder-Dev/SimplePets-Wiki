# Camel
| Permission Node | Description |
| - | - |
| pet.type.camel | Will allow the player to spawn the Camel pet |
| pet.type.camel.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.camel.fly | Will allow the Camel to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.camel.hat | Will allow the Camel to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.camel.mount | Will allow the Camel to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.camel.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data camel</mark>) |
| pet.type.camel.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.camel.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.camel.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.camel.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.camel.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.camel.data.baby | Will allow the player to view/toggle the 'Baby' Data Item |
| pet.type.camel.data.sitting | Will allow the player to view/toggle the 'Sitting' Data Item |
