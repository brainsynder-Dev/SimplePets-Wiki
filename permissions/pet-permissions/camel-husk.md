# Camel Husk
| Permission Node | Description |
| - | - |
| pet.type.camelhusk | Will allow the player to spawn the Camel Husk pet |
| pet.type.camelhusk.* | Grants full access to the pet, such as spawning the pet, flying, mounting, hat, and all the data items |
| pet.type.camelhusk.fly | Will allow the Camel Husk to fly <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.camelhusk.hat | Will allow the Camel Husk to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.camelhusk.mount | Will allow the Camel Husk to be a hat <mark style="color:green;">`(If enabled)`</mark> |
| pet.type.camelhusk.data.* | Grants full access to all the data toggles for modifying the pet (<mark style="color:red;">/pet data camel_husk</mark>) |
| pet.type.camelhusk.data.half_scale<br><mark style="color:orange;"><code>(Added in R5-B294)</code></mark> | Will allow the player to view/toggle the 'Half Scale' Data Item |
| pet.type.camelhusk.data.visible<br><mark style="color:orange;"><code>(Added in v5.0-BUILD-122)</code></mark> | Will allow the player to view/toggle the 'Visible' Data Item |
| pet.type.camelhusk.data.frozen | Will allow the player to view/toggle the 'Frozen' Data Item |
| pet.type.camelhusk.data.burning | Will allow the player to view/toggle the 'Burning' Data Item |
| pet.type.camelhusk.data.silent | Will allow the player to view/toggle the 'Silent' Data Item |
| pet.type.camelhusk.data.baby | Will allow the player to view/toggle the 'Baby' Data Item |
| pet.type.camelhusk.data.sitting | Will allow the player to view/toggle the 'Sitting' Data Item |
