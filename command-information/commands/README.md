# Commands

Every command below is a sub-command of <mark style="color:green;">`/pet`</mark>, \
which can also be run as <mark style="color:green;">`/pets`</mark>, <mark style="color:green;">`/simplepets`</mark>, or <mark style="color:green;">`/simplepet`</mark>

If you are aiming to give a player all the command access \
then you can give them the permission: <mark style="color:green;">`pet.commands.*`</mark>
