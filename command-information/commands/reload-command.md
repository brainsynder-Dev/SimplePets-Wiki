# Reload Command

{% hint style="danger" %}
This command is considered an _<mark style="color:red;">**ADMIN ONLY**</mark>_ command\
Ordinary players should _<mark style="color:red;">**NOT**</mark>_ be given access to this command
{% endhint %}

## What does this command do?

Reloads the files the plugin uses so your changes are applied without a server restart.

## Command Usage

> <mark style="color:orange;">`<>`</mark> = REQUIRED
>
> <mark style="color:blue;">`[]`</mark> = OPTIONAL
>
> Usage: /pet reload
>
> Usage: /pet reload config
>
> Usage: /pet reload messages
>
> Usage: /pet reload inventories
>
> Usage: /pet reload particles
>
> Usage: /pet reload pets

### Usage Descriptions

| Usage | Description |
| - | - |
| /pet reload | <p>Reloads the config, messages, particles, pet configs, inventories, and items<br>Example: <mark style="color:green;"><code>/pet reload</code></mark></p> |
| /pet reload config | <p>Reloads the config file<br>Example: <mark style="color:green;"><code>/pet reload config</code></mark></p> |
| /pet reload messages | <p>Reloads the messages file<br>Example: <mark style="color:green;"><code>/pet reload messages</code></mark></p> |
| /pet reload inventories | <p>Reloads the inventory and item files<br>Example: <mark style="color:green;"><code>/pet reload inventories</code></mark></p> |
| /pet reload particles | <p>Reloads the particle files<br>Example: <mark style="color:green;"><code>/pet reload particles</code></mark></p> |
| /pet reload pets | <p>Reloads the pet config files<br>Example: <mark style="color:green;"><code>/pet reload pets</code></mark></p> |

## Permissions

| Permission Node | Description |
| - | - |
| pet.commands.reload | Grants the player access to run <mark style="color:red;">`/pet reload`</mark> and all of its sub-commands |
