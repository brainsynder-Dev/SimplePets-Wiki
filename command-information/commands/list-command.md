# List Command

{% hint style="info" %}
This command players are given access to by <mark style="color:orange;">`DEFAULT`</mark>
{% endhint %}

## What does this command do?

Lists every pet type, colored by whether it is usable. Hover over a pet to see why it can not be used.

## Command Usage

> <mark style="color:orange;">`<>`</mark> = REQUIRED
>
> <mark style="color:blue;">`[]`</mark> = OPTIONAL
>
> Usage: /pet list

### Usage Descriptions

| Usage | Description |
| - | - |
| /pet list | <p>Lists all the pet types <mark style="color:green;">`(disabled, unsupported, unregistered, and in development pets are colored differently)`</mark><br>Example: <mark style="color:green;"><code>/pet list</code></mark></p> |

## Permissions

| Permission Node | Description |
| - | - |
| pet.commands.list | Grants the player access to run <mark style="color:red;">`/pet list`</mark> |
