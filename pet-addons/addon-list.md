# Addon List

{% hint style="info" %}
Every addon listed here can be installed straight from the <mark style="color:red;">`/pet addon`</mark> GUI, or with the [Addon Command](../command-information/commands/addon-command.md)\
Example: <mark style="color:red;">`/pet addon install Vault`</mark>
{% endhint %}

{% hint style="warning" %}
The versions below are only a snapshot, the live list is the one inside the <mark style="color:red;">`/pet addon`</mark> GUI or on the [Addon Site](https://bsdevelopment.org/addons/SimplePets)
{% endhint %}

All the addons below are made/posted by <mark style="color:green;">`brainsynder`</mark>

## Economy

These let your players buy pets with an in-game currency, see [HOW CAN I MAKE IT SO PLAYERS CAN PURCHASE PETS](../faq.md#how-can-i-make-it-so-players-can-purchase-pets)

| Addon                                                       | Description                                                                     | Version |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------- | ------- |
| [GemsEconomy](https://modrinth.com/plugin/xsmXzPYu)         | Hooks into the GemsEconomy plugin to allow pets to be purchased via in-game currency | 0.2     |
| [ItemEconomy](https://modrinth.com/plugin/wGMWezGi)         | Allows players to purchase pets via in-game items!                              | 0.1     |
| [PlayerPoints](https://modrinth.com/plugin/HZVEuuUz)        | Hooks into the PlayerPoints plugin to allow pets to be purchased via in-game currency | 0.1     |
| [TokenManager](https://modrinth.com/plugin/GFserI2n)        | Hooks into the TokenManager plugin to allow pets to be purchased via in-game currency | 0.2     |
| [Treasury](https://modrinth.com/plugin/8Ol0Pe1v)            | Hooks into the Treasury plugin to allow pets to be purchased via in-game currency | 0.3     |
| [Vault](https://modrinth.com/plugin/ou5R1FPW)               | Hooks into the Vault plugin to allow pets to be purchased via in-game currency  | 0.4     |

## Regions & Protection

These control where pets are allowed to be spawned, ridden, or moved, see [MY WORLD GUARD FLAGS DO NOT SEEM TO BE WORKING](../faq.md#my-world-guard-flags-do-not-seem-to-be-working)

| Addon                                                       | Description                                                                     | Version |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------- | ------- |
| [GriefPrevention](https://modrinth.com/plugin/etWLQCRo)     | Hooks into GriefPrevention to stop specific pet events from occurring when on or off of claimed land | 0.3     |
| [PlotSquared](https://modrinth.com/plugin/8wmPkXSD)         | Hooks into the PlotSquared plugin to allow/deny certain pet events from happening on certain parts of a plot world (road/unclaimed/denied) | 0.5     |
| [RedProtect](https://modrinth.com/plugin/Ibb6L7Y5)          | Hooks into RedProtect adding a few flags to the plugin, such as pet-spawning, pet-moving, pet-riding, and pet-mounting | 0.2     |
| [Residence](https://modrinth.com/plugin/bpOB60Kn)           | Hooks into Residence so that you can stop specific pet events in selected areas | 0.1     |
| [WorldBorder](https://modrinth.com/plugin/5Ll3csHU)         | Hooks into the WorldBorder plugin so you can stop specific pet events from occurring when outside of borders | 0.2     |
| [WorldGuard](https://modrinth.com/plugin/awjT0Z11)          | Hooks into WorldGuard so that you can stop specific pet events in regions       | 0.6     |

## Other

| Addon                                                       | Description                                                                     | Version |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------- | ------- |
| [PermissionLore](https://modrinth.com/plugin/c3OLWnep)      | Simply adds a lore to the pet items if they do/don't have permission for the pet | 0.1     |
| [PetWeight](https://modrinth.com/plugin/DkVBtrLX)           | Pets have actual weight and slow the player down when they are on top of the players head (the weight stacks with more pets) | 0.4     |
| [PvP](https://modrinth.com/plugin/1lrvq5n8)                 | Checks for when the owner of a pet is in combat and will remove all their current pets | 0.3     |
| [Vanish](https://modrinth.com/plugin/uuSpJLnQ)              | Hooks into the Super/Premium Vanish plugin(s) to make the pets vanish when the player is vanished | 0.2     |
| [WorldRestriction](https://modrinth.com/plugin/LDJFcdu0)    | This addon simply restricts certain tasks from happening in certain worlds      | 0.2     |
